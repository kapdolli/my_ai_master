# 국어강사아이템 — 실행 프롬프트

> 이 프롬프트는 로컬 Python 실행(`run_local.py`)이 Claude Code CLI(`claude -p`)에 전달하는 사양이다.
> 대상 페르소나(**중고등 국어강사 · 학원 운영 10년 · 50대 중반 여성**)에 특화된 부업/경력전환 아이템을 조사·정리한다.
> 발송은 로컬 스크립트가 처리하므로, 최종 응답은 리포트 본문 텍스트만 출력한다.
> 이 서비스는 **on-demand** 이며 스케줄로 자동 실행되지 않는다 — 사용자가 명시적으로 요청할 때만 호출한다.

---

## 대상 페르소나 (고정값)

| 항목 | 값 |
|------|-----|
| 직업 | 현직 국어강사 (학원) |
| 나이 · 성별 | 50대 중반 · 여성 |
| 경력 | 국어강사 장기 경력 + 학원 운영 약 10년 (현재는 강사 재직) |
| 담당 | 중학교·고등학교 국어 전문 (문학·비문학·문법·독해·수능/내신) |
| 학력 | 국어국문학과 출신, 글쓰기 · 첨삭 · 논술 지도 가능 |
| 상황 | 강사 자리가 갈수록 줄어드는 시장 환경. 그동안의 경험(강의·운영·글쓰기)을 살릴 수 있는 새 수익원 필요 |
| 제약 | 밑바닥 코딩·영상편집·대규모 초기 투자 어려움. 시간·건강·체력 고려 |

이 프로필이 바뀌면 이 섹션을 편집한다.

## 목표

위 페르소나가 **본인 경험(국어 콘텐츠·학생 지도·학원 운영·글쓰기)을 자산 삼아 시작할 수 있는** 부업·1인 창업·경력 전환 아이템을 국내외 사례와 함께 조사해 실행 가능성 순으로 정리한다.

## [STEP 1] 검색

`web_search` 툴로 아래 소스에서 관련 사례·아이템을 최신순으로 수집한다.

**국내 우선 (페르소나 특성상 국내 채널이 실효적):**
- 크몽 / 탈잉 / 클래스101 / 인프런 — "국어 첨삭", "논술 지도", "글쓰기 코치", "독서 지도", "북튜버 컨설팅", "수능 국어" 관련 판매자·강의
- 네이버 카페·블로그 — "학원 원장 부업", "국어강사 부업", "50대 여성 창업", "은퇴 강사 제2막"
- 유튜브 교육 채널 — 국어·독서·글쓰기 계열 1인 크리에이터 성공 사례 (구독자·수익 공개된 것 위주)
- 브런치 · 리디북스 셀프퍼블리싱 — 국어/글쓰기 작가 사례
- 잡코리아 · 워크넷 — 국어강사 경력자 대상 채용/프리랜서 트렌드
- 뉴스·매거진 — 학령인구 감소·학원업 재편·평생교육·시니어 창업 관련 최근 기사

**해외 참고 (벤치마킹용):**
- Substack / Medium / Patreon — 언어·글쓰기·독서 뉴스레터·유료 커뮤니티 사례
- Outschool / Preply / italki — 언어 교사 1인 온라인 튜터링 플랫폼 수익 사례
- Reddit r/Teachers, r/Tutor, r/writing — 교사 부업/전직 스레드
- IndieHackers — 에듀·라이팅·코칭 카테고리 성공 사례

각 소스에서 2~4개씩, **총 15~25개 후보**를 모은다.

## [STEP 2] 분석 및 평가

각 후보를 아래 축으로 평가한다.

- **카테고리**:
  - 📝 1:1 지도·코칭 (온라인 첨삭·과외·논술 코칭 등)
  - 🎥 콘텐츠 크리에이터 (유튜브·블로그·뉴스레터·팟캐스트)
  - 📚 지식상품 판매 (전자책·강의·문제집·워크북·PDF 자료)
  - 🏫 커뮤니티·클래스 운영 (독서모임·글쓰기 워크숍·소규모 프리미엄 클래스)
  - 💼 B2B·프리랜서 (출판 편집·기업 글쓰기 교육·교재 집필·논술학원 컨설팅)
  - 🌱 경력 전환·자격 (진로 상담·평생교육사·시니어 대상 교육 등)
- **초기 진입 난이도**: 상/중/하 (기술·자본·시간 기준으로 이 페르소나가 90일 내 첫 매출을 낼 수 있는가)
- **경험 적합도** ★1~5: 국어·학원운영·글쓰기 경험이 얼마나 직접 활용되는가
- **수익 가능성** ★1~5: 시장 크기·객단가·재구매 가능성
- **AI 활용 여지** ★1~5: ChatGPT/Claude로 첨삭·자료 제작·마케팅을 얼마나 자동화·확장할 수 있는가
- **지속 가능성**: 이 페르소나가 5년 이상 끌고 갈 만한 성격(건강·번아웃 리스크·확장성)에 대한 1문장 코멘트

상위 10개를 선별하고, 카테고리가 한쪽에 몰리지 않게 최소 3개 카테고리 이상 포함시킨다.

## [STEP 3] 리포트 출력

선별된 10개를 아래 포맷으로 구성해 **최종 응답 텍스트로 출력**한다. 별도의 발송·저장·툴 호출은 하지 않는다 — 로컬 스크립트가 이 응답을 받아 텔레그램으로 분할 발송한다.

리포트 포맷 (Markdown, 텔레그램 plain text로 렌더됨. 코드 펜스로 감싸지 말 것):

```
📚 국어강사 아이템 리포트 YYYY-MM-DD
페르소나: 중고등 국어강사 · 학원운영 10년 · 국문과 출신 · 50대 중반
총 {N}개 아이템 선별

📝 1:1 지도·코칭
────────────────────
① [아이템명]
  한 줄 요약: ...
  진입난이도: 하 | 경험적합도: ★★★★★ | 수익성: ★★★★ | AI활용: ★★★
  왜 이 페르소나에게 맞나: 1~2문장 (본인의 어떤 경험이 직접 자산이 되는지)
  국내 사례: 서비스/사람 이름 + 규모 감 (수강생 수, 월매출 등 공개된 것)
  첫 3개월 실행 스텝: 1) ... 2) ... 3) ...
  지속성 코멘트: 1문장
  원문: {URL}

② [아이템명]
...

🎥 콘텐츠 크리에이터
────────────────────
...

📚 지식상품 판매
────────────────────
...

🏫 커뮤니티·클래스 운영
────────────────────
...

💼 B2B·프리랜서
────────────────────
...

🌱 경력 전환·자격
────────────────────
...

📌 오늘의 추천 픽 (즉시 실행 가능성 기준)
1. ①번 — 이유: 페르소나 강점과 정확히 맞고 90일 내 첫 매출 가능성 높음
2. ...
3. ...

⚠ 반드시 피하거나 신중해야 할 유형 (선택)
- 예: 초기 자본 3천만 원 이상 오프라인 교습소 신설 — 학령인구 감소 흐름과 역행
```

### 출력 규칙

- 응답은 위 포맷의 마크다운 본문만 담는다. 도입 인사·후기·코드펜스 금지.
- 각 아이템에 반드시 원문 URL을 첨부한다 (검색 결과에서 확보한 실제 URL만).
- 카테고리가 비면 헤더 자체를 생략한다.
- 페르소나 특성상 **국내 실행 관점**을 우선한다. 해외 사례는 벤치마킹용으로만 언급하되, "국내 이식 시 필요한 조정 1줄"을 반드시 붙인다.
- 근거 없는 수치·과장 마케팅 문구 금지. 공개된 수치만 인용하고 출처 URL 첨부.
- "AI 활용" 항목은 이 페르소나가 실제로 다룰 수 있는 수준(ChatGPT 유료 · Claude 웹 · GPTs · 노코드 자동화) 안에서 제안한다.
- 날짜 `YYYY-MM-DD`는 시스템 프롬프트 상단에 제시된 `오늘 날짜(KST)` 값을 그대로 쓴다.
